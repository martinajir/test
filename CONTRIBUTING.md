# Contributing a Recipe

Thanks for adding to the recipe repository! To keep things consistent:

1. Copy [`recipes/TEMPLATE.md`](recipes/TEMPLATE.md) to a new file in `recipes/`, named in `kebab-case.md` matching the recipe title (e.g. `corn-chowder.md`).
2. Fill in the title, description, servings, prep/cook time, tags, ingredients, and numbered instructions.
3. Add a link to your new recipe in the table in `README.md`, keeping the list alphabetized by recipe name.
4. Open a pull request. Please keep one recipe per file and one recipe per PR when possible.

## Style guidelines

- Use `##` for section headers (`Ingredients`, `Instructions`).
- Write ingredients as a bulleted list with quantities first (e.g. `2 cups flour`).
- Write instructions as a numbered list of clear, actionable steps.
- Keep tags lowercase and comma-separated (e.g. `soup, vegetarian, quick`).
